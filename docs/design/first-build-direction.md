# First-build visual direction

Developer proposal, implemented for local review on 28 October 2026; user visual approval remains pending.

Student workspace: a readable ordered learning path on a pale blue-gray surface, white lesson/question panels, deep teal actions, and a compact carbon-inspired ChemTrack mark. System Segoe UI/sans typography avoids font downloads. Numbered markers represent actual activity order, not decoration. Desktop sidebar becomes a compact phone header. Keyboard focus, labeled answers, status/error messages and reduced-motion support are included.

Tokens: ink `#203341`, muted text `#536978`, primary `#125e59`, page `#f3f6f8`, borders `#dce5ea`, active surface `#e5f0ef`. UI text distinguishes confirmed saved answers from pending/failed saves. Scores and completion progress are separate concepts.

Teacher workspace uses Filament with teal actions and local/system font configuration. No external fonts, analytics or stock photos are required. Browser screenshots are in ignored `.local/previews/` and contain synthetic demo records.

Observed checks: Chromium-based Chrome desktop at 1440px and emulated 390px student layout. This is not a real-device check or full accessibility audit. Proposed visual refinements should preserve the functional learning sequence and save feedback.
