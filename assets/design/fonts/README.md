# Preview font sources

Retrieved 29 October 2026 from the Google Fonts repository for the proposed typography/theme preview. Not installed as system fonts. The original TTFs stay here; licensed WOFF2 derivatives in `resources/fonts/` now serve the application.

- `manrope-variable.ttf`: [Manrope source](https://github.com/google/fonts/tree/main/ofl/manrope), SIL Open Font License, included in `manrope-license.txt`.
- `inter-variable.ttf`: [Inter source](https://github.com/google/fonts/tree/main/ofl/inter), SIL Open Font License, included in `inter-license.txt`.

Keep both license files with redistributed font files. The current application serves optimized webfonts locally with fallback fonts and swap loading. These original TrueType sources are retained for accurate preview rendering.
