# ChemTrack webfonts

Self-hosted variable WOFF2 versions of the source fonts in assets/design/fonts/.
Manrope is used for headings; Inter is used for body text and controls.
Both retain their bundled SIL Open Font License files. Converted from the
existing source TTFs using FontTools 4.68.0 and Brotli 1.2.1 on 29 October 2026.
